# Landing Page — Agência THAS

Landing page da **Agência THAS**, agência de cobertura de eventos (stories, reels, fotos e vídeos) com sede em Brasília - DF.

## Seções

- **Hero**: apresentação e chamadas para orçamento e portfólio
- **Serviços**: Stories & Reels, Cobertura de Eventos e Vídeo Profissional
- **Portfólio**: galeria de fotos com filtro por categoria (casamentos, festas, eventos)
- **Estatísticas**: números da agência
- **Equipe**: quem está por trás das histórias
- **Depoimentos**: avaliações de clientes
- **Contato**: formulário, WhatsApp, Instagram e e-mail

## Tecnologias

- HTML5
- CSS3 (um arquivo por seção, com variáveis em `variables.css`)
- JavaScript puro (sem frameworks ou dependências)

## Estrutura do projeto

```
Landing-Page-Storymakers/
├── index.html
└── src/
    ├── css/        # estilos por seção (navbar, hero, servicos, portifolio, ...)
    ├── images/     # hero, portfolio e equipe
    └── js/
        └── script.js
```

## Funcionalidades em JavaScript

- Navbar que muda de estilo ao rolar a página (classe `scrolled`)
- Filtro do portfólio por categoria, usando `data-filter` e `data-categoria`

## Como executar

Não há instalação nem build. Basta clonar o repositório e abrir o `index.html` no navegador:

```bash
git clone https://github.com/SEU-USUARIO/Landing-Page-Storymakers.git
cd Landing-Page-Storymakers
```

Se preferir, use a extensão **Live Server** do VS Code para recarregar automaticamente.
